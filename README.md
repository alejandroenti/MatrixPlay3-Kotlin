# 🕹️ MatrixPlay3-Kotlin

*Like the classic **Pong**, but in Kotlin.*

## 🎯 Main Features
- Real-Time online multiplayer with WebSockets.
- Tactile controls for more precision with the pad.
- Play it everywhere!

## 🧰 Used Technologies
- Kotlin -> Minimum SDK (API 24).
- WebSockets.

## 🚀 Execute proyect
1. Clone GitHub repository.
```bash
git clone https://github.com/alejandroenti/MatrixPlay3-Kotlin.git
```
2. Open Android Studio.
3. Select *Open* option and select the repository folder.

![alt text](<resources/Captura de pantalla de 2025-11-07 16-16-13.png>)

4. Build the solution.
5. Execute on your emulator.
